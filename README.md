# 📺 IPTV Mundial

Lista IPTV gratuita com **17.038** canais de **180** países, organizada por país e categoria. Atualizada automaticamente toda semana a partir da base pública [iptv-org](https://github.com/iptv-org/iptv) — só canais que as próprias emissoras disponibilizam abertamente.

_Última atualização: 09/10/2026_

## 🚀 Como usar

Cole a URL abaixo no seu app de IPTV (IPTV Smarters, TiviMate, GSE Smart IPTV, iPlayTV, Flex IPTV, VLC, Kodi…):

```
https://raw.githubusercontent.com/0uand/iptv-mundial/main/index.m3u
```

Ou use apenas um país / categoria com as URLs das tabelas abaixo. O guia de programação (EPG) já está configurado dentro da lista.

## ⚠️ Avisos

- Em listas públicas, parte dos canais pode estar fora do ar em um dado momento — a lista é regenerada semanalmente para remover links mortos conhecidos.
